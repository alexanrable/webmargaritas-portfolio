# WebMargaritas Portfolio

**A self-developed advertising services marketplace**

🌐 **Live website:** [webmargaritas.com](https://www.webmargaritas.com/)

## Overview

WebMargaritas is a web platform for browsing and ordering digital advertising services across multiple platforms.

I developed and deployed the website independently, working on both the application and its production environment.

## Key Features

- Service catalog with categories and platform filters
- Individual service pages
- Shopping cart and order management
- Case studies and customer reviews
- Responsive user interface
- Server-side application and production deployment

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Web server:** Nginx
- **Process management:** PM2
- **Environment:** Linux
- **Version control:** Git, GitHub

## My Responsibilities

- Designed and implemented website features
- Developed frontend and backend functionality
- Deployed the application to a Linux server
- Configured the production web server and application process
- Tested functionality, investigated issues, and fixed bugs
- Maintained the codebase using Git

## Project Status

The website is live. The source code is kept private, so this repository serves as a public project overview and portfolio.
